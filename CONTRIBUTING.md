# Colaborar en LAST KEY

El repositorio público permite colaborar mediante forks y pull requests.

1. Abre un issue breve con el cambio o error que vas a trabajar.
2. Haz un fork y crea una rama: `fix/descripcion` o `feature/descripcion`.
3. Sigue `SETUP_COLABORADORES.md` para preparar Unity y las fuentes visuales locales.
4. Haz cambios pequeños por área; evita editar la misma escena o prefab simultáneamente.
5. Ejecuta las pruebas adecuadas y abre un pull request explicando qué cambió y cómo lo probaste.

Antes de mezclar, comprueba que se conservan estas reglas:

- Cuatro participantes; gana la mayor puntuación acumulada tras todas las rondas.
- Danger 100% elimina únicamente de la ronda actual.
- NULL dirige pruebas; ECHO propone riesgos opcionales.
- No presentar salas, Chaos ni Story Mode como implementados.

Conserva `.meta`, mantén recursos de terceros con su atribución y no subas `Library`, `Builds`, credenciales ni fuentes privadas ActorCore/Mixamo. No incluyas música, voces o recursos nuevos sin documentar su procedencia.

Para acceso directo de escritura, Fernando puede invitar a los compañeros desde Settings → Collaborators. Hasta entonces, fork + pull request permite proponer cambios sin modificar `main` directamente.
